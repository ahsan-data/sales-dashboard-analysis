------------------------------------------------------------

📌 OVERVIEW
------------------------------------------------------------
This project analyzes 12 months of retail sales data (50,000+ records) to identify revenue trends, top-selling products, and customer segments.
Insights are visualized using Python and Power BI.

🛠️ TOOLS & TECHNOLOGIES
------------------------------------------------------------
- Python      : Data cleaning & EDA
- Pandas      : Data manipulation
- SQL         : Querying & aggregation
- Power BI    : Interactive dashboard
- Matplotlib  : Data visualization

💡 KEY INSIGHTS
------------------------------------------------------------
- Top 3 products contribute ~67% of total Q4 revenue
- November shows consistent peak performance (+43% MoM growth)
- VIP customers (8% of users) generate 52% of total revenue
